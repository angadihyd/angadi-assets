Order Windows

Controls when customers can place an order and which delivery date it's for — enforced on the website's checkout and the WhatsApp bot. All times are IST.
Example: to take orders for Sunday delivery, set delivery date = that Sunday, "opens from" = when you want to start taking orders (e.g. Thursday), "closes at" = your cutoff (e.g. Saturday 8 PM).
